# 💰 جیبت — Jibet

اپلیکیشن مدیریت مالی شخصی، **کاملاً آفلاین**، سریع و یک‌دستی — ساخته‌شده با Kotlin و Jetpack Compose.

**نسخه ۲.۰** — بازطراحی کامل با همان طراحی نسخه وب (preview panel): سطوح شیشه‌ای، کارت‌های نرم، نویگیشن شناور با دکمه مرکزی، آیکون‌های حبابی رنگی، ۴ رنگ برنامه قابل انتخاب (آبی/سبز/بنفش/نارنجی)، آنبوردینگ پنج‌مرحله‌ای، داده نمونه و گزارش دایره‌ای/میله‌ای.

## ✨ امکانات

- ⚡ **ثبت سریع هزینه و درآمد** با کیبورد عددی اختصاصی (مناسب یک‌دستی)
- 🗂️ **دسته‌بندی‌های قابل شخصی‌سازی** با آیکون و رنگ
- 💰 **بودجه ماهانه برای هر دسته** با نمایش پیشرفت مصرف
- 💳 **چند حساب** (نقدی، کارت بانکی، کیف پول و…) با موجودی خودکار
- 🔁 **تراکنش‌های تکراری** (اجاره، حقوق و…) که خودکار در سررسید ثبت می‌شوند
- 🎯 **اهداف پس‌انداز** با نوار پیشرفت و مهلت
- 📊 **گزارش‌های دایره‌ای و میله‌ای** ماهانه / هفتگی / سالانه + روند
- 🔍 **جستجو و فیلتر پیشرفته** (نوع، دسته، حساب، بازه زمانی)
- 📅 **تاریخ شمسی** در همه‌جا (الگوریتم jalaali، مطابق نسخه وب)
- 🧾 **خروجی Excel/CSV** و **پشتیبان‌گیری/بازیابی کامل** (JSON سازگار با نسخه وب)
- 🧊 رابط کاربری **Liquid Glass** مینیمال با رنگ‌های ملایم و انیمیشن‌های سبک
- 🎨 **۴ رنگ برنامه** قابل انتخاب از بخش «بیشتر»
- 🧪 **داده‌ی نمونه** برای تست سریع (از بخش بیشتر → داده‌ها)
- 🔒 کاملاً آفلاین — هیچ داده‌ای از دستگاه خارج نمی‌شود

## 🛠 تکنولوژی

| لایه | ابزار |
|---|---|
| زبان | Kotlin 2.0 |
| UI | Jetpack Compose + Material 3 |
| دیتابیس | Room (SQLite) — کاملاً آفلاین |
| معماری | MVVM (ViewModel + Repository + Flow) |
| تنظیمات | Jetpack DataStore |
| تاریخ | تقویم جلالی (پورت jalaali-js — یکسان با نسخه وب) |
| فونت | وزیرمتن |

## 🚀 اجرا از سورس

نیازمندی: Android Studio (Koala+) و JDK 17

```bash
git clone https://github.com/Amirem24/jibet.git
```

سپس پروژه را در Android Studio باز کنید و Run بزنید. نسخه CLI:

```bash
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

CI این ریپو با هر push روی `main` به‌صورت خودکار APK را می‌سازد و در Releases و پوشه `apk/` قرار می‌دهد.

## 📁 ساختار

```
app/src/main/java/com/jibet/app/
├── MainActivity.kt        # ناوبری، نوار پایین، پس‌زمینه شیشه‌ای
├── JibetApp.kt            # Application + تزریق وابستگی سبک
├── data/                  # Room: Entities, DAOs, Repository, Settings
├── util/                  # تقویم شمسی، فرمت اعداد فارسی، داده‌های پیش‌فرض
└── ui/
    ├── theme/             # پالت ملایم + تم روشن/تاریک
    ├── components/        # GlassCard و کامپوننت‌های مشترک
    ├── setup/             # ویزارد راه‌اندازی اولیه
    ├── home/  stats/  add/  transactions/
    ├── categories/  accounts/  goals/  recurring/
    └── settings/          # پشتیبان‌گیری، خروجی CSV، تم، واحد پول
```
