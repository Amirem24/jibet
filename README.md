# 💰 جیبت — Jibet

اپلیکیشن مدیریت مالی شخصی، **کاملاً آفلاین**، سریع و یک‌دستی — ساخته‌شده با Kotlin و Jetpack Compose.

**نسخه ۲.۳.۲** — بازطراحی کامل با همان طراحی نسخه وب (preview panel): سطوح شیشه‌ای، کارت‌های نرم، نویگیشن شناور با دکمه مرکزی، آیکون‌های حبابی رنگی، ۴ رنگ برنامه قابل انتخاب (آبی/سبز/بنفش/نارنجی)، آنبوردینگ پنج‌مرحله‌ای، داده نمونه و گزارش دایره‌ای/میله‌ای.

## ✨ امکانات

- ⚡ **ثبت سریع هزینه و درآمد** با کیبورد عددی اختصاصی (مناسب یک‌دستی)
- 🗂️ **دسته‌بندی‌های قابل شخصی‌سازی** با آیکون و رنگ
- 💰 **بودجه ماهانه برای هر دسته** با نمایش پیشرفت مصرف
- 💳 **چند حساب** (نقدی، کارت بانکی، کیف پول و…) با موجودی خودکار
- 🔁 **تراکنش‌های تکراری** (اجاره، حقوق و…) که خودکار در سررسید ثبت می‌شوند
- 🎯 **اهداف پس‌انداز** با نوار پیشرفت و مهلت
- 📊 **گزارش‌های دایره‌ای و میله‌ای** ماهانه / هفتگی / سالانه + روند
- 🔍 **جستجو و فیلتر پیشرفته** (نوع، دسته، حساب، بازه زمانی)
- 📅 **تاریخ شمسی** در همه‌جا (الگوریتم jalaali، مطابق نسخه وب)
- 🧾 **خروجی Excel/CSV** و **پشتیبان‌گیری/بازیابی کامل** (JSON سازگار با نسخه وب)
- 🧊 رابط کاربری **Liquid Glass** مینیمال با رنگ‌های ملایم و انیمیشن‌های سبک
- 🎨 **۴ رنگ برنامه** قابل انتخاب از بخش «بیشتر»
- 🧪 **داده‌ی نمونه** برای تست سریع (از بخش بیشتر → داده‌ها)
- 🔒 کاملاً آفلاین — هیچ داده‌ای از دستگاه خارج نمی‌شود

## 🐛 تغییرات نسخه ۲.۳.۲ — دیباگ و پایداری

- **رفع باگ بحرانی آنبوردینگ:** دسته‌های درآمد (حقوق، فروش، هدیه…) و نوع حساب‌ها (بانکی، کیف پول…) به‌علت حساسیت توابع تبدیل به حروف بزرگ/کوچک، همه اشتباه ذخیره می‌شدند؛ اصلاح شد + تست رگرسیون (`EnumFromTest`).
- **بازیابی امن‌تر بکاپ:** فایل پشتیبان پیش از هر پاک‌سازی به‌طور کامل اعتبارسنجی می‌شود؛ ارجاع یا تاریخ خراب دیگر بی‌صدا داده‌ای را حذف نمی‌کند.
- **حریم خصوصی:** بکاپ خودکار اندروید/گوگل غیرفعال شد (`allowBackup=false`) تا دیتابیس مالی از دستگاه خارج نشود — هم‌سو با «کاملاً آفلاین».
- **جستجو:** نویسه‌های `%` و `_` دیگر وایلدکارد SQL نیستند و literal جستجو می‌شوند.
- **خروجی CSV:** خنثی‌سازی تزریق فرمول اکسل و حفظ اعشار مبلغ.
- **پایداری:** فایل خراب تنظیمات (DataStore) دیگر اپ را کرش نمی‌کند؛ ستاپ آنبوردینگ و واریز به هدف اتمیک شدند؛ سقف جبران تراکنش‌های تکراری عقب‌افتاده از ۲۰۰ به ۱۰۰۰ رسید.
- گزارش کامل دیباگ در فایل `DEBUG-REPORT.md`.

## 🚀 اجرا از سورس

نیازمندی: Android Studio (Koala+) و JDK 17

```bash
git clone https://github.com/Amirem24/jibet.git
```

سپس پروژه را در Android Studio باز کنید و Run بزنید. نسخه CLI:

```bash
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

CI این ریپو با هر push روی `main` به‌صورت خودکار APK را می‌سازد و در Releases و پوشه `apk/` قرار می‌دهد.

## 📁 ساختار

```
app/src/main/java/com/jibet/app/
├── MainActivity.kt        # ناوبری، نوار پایین، پس‌زمینه شیشه‌ای
├── JibetApp.kt            # Application + تزریق وابستگی سبک
├── data/                  # Room: Entities, DAOs, Repository, Backup, Settings
├── util/                  # تقویم شمسی، فرمت اعداد فارسی، پریست‌ها
└── ui/
    ├── theme/             # پالت ملایم + تم روشن/تاریک
    ├── components/  nav/  # GlassCard، کامپوننت‌های مشترک، ناوبری پایین
    ├── onboarding/        # ویزارد راه‌اندازی اولیه
    ├── home/  transactions/  sheets/  search/  reports/
    ├── budget/  categories/  accounts/  goals/  recurring/
    └── more/  backup/  about/   # پشتیبان‌گیری، خروجی CSV، تم، داده نمونه
```
